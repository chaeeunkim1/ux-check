# UX Check

업무 화면의 UI·UX 문제를 근거와 함께 검토하고 개선 요청으로 정리하는 AI 검수 도구를 개발하는 프로젝트입니다.

## 현재 상태

해커톤 실행 전 GitHub 연결을 준비하는 초기 저장소입니다. 앱 구현, 실제 AI API 연결, 공개 데모 배포는 아직 진행하지 않았습니다.

## 구현할 사용자 흐름

1. 업무 화면 캡처와 사용자의 업무 목적을 입력합니다.
2. AI가 화면의 문제 위치, 관찰 근거, 업무 영향과 개선안을 정리합니다.
3. 개선 전후 화면을 비교하고 검수 보고서를 내려받습니다.

공개 예제에는 합성 화면과 데이터만 사용할 계획입니다. 실제 동작과 검증 결과는 구현 후 이 문서에 업데이트합니다.

## 개발 준비

- 실제 실행할 /goal은 실행 전에 확정하고, 입력한 원문을 별도로 보존합니다.
- API 키는 서버 환경변수로 설정하며 소스 코드나 공개 문서에 기록하지 않습니다.
- Codex 원본 JSONL과 비공개 자료는 공개 저장소에 포함하지 않습니다.
- 실행 방법, 테스트 결과, 데모·영상 링크와 발표자료는 구현 후 추가합니다.
