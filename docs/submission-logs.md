# 제출용 세션 로그

API 키는 교체하지 않고 기존 키를 계속 사용합니다. 원본 대화와 원본 JSONL에는 키가 남을 수 있으므로, 원본을 그대로 업로드하지 않습니다.

## 내보내기

대회 실행이 끝난 뒤 실제 /goal과 결과가 포함된 주 세션 하나를 선택합니다. 아래 스크립트는 원본을 읽기만 하고 별도 제출 사본을 만듭니다.

```powershell
python scripts/export-submission-logs.py --main "원본 주 세션.jsonl" --extra "추가 세션.jsonl" --output "artifacts/submission/final-20260922"
```

추가 세션이 없으면 --extra를 생략합니다. 여러 개면 --extra를 반복합니다. 출력 폴더는 새 폴더여야 하며 기존 결과를 덮어쓰지 않습니다.

- main.jsonl: 주 세션의 비밀값 제거 사본.
- additional-sessions.zip: 추가 세션이 있을 때만 생성하며, 비밀값 제거 사본만 포함.
- redaction-manifest.json: 원본/사본 해시, 행 수, 변경 목적과 치환 수. 심사 시 비밀값만 가렸음을 함께 설명합니다.

로컬 .env.local의 키·토큰 값과 알려진 API 키 형식을 [REDACTED_SECRET]으로 치환합니다. 중첩된 도구 명령과 대화에도 적용합니다. 이벤트를 삭제하거나 실행 시간, 토큰 수, 성과를 변경하지 않습니다. /goal에 비밀값이 없는 한 원문 문자열을 유지합니다. 이미지 데이터도 이 스크립트에서는 그대로 보존합니다.

JSONL을 다시 파싱하고 ZIP 안의 각 파일을 열어 키 잔존을 검사합니다. 파싱 실패 또는 키 잔존 시 내보내기를 실패 처리합니다. 알려지지 않은 형식의 회사 정보나 화면 속 비밀값은 별도 확인이 필요합니다.

## 제출 직전

1. 실제 실행이 끝난 최신 로그로 다시 내보냅니다. 준비 단계의 snapshot은 최종 제출 로그가 아닙니다.
2. 실제 입력한 /goal이 포함됐는지, 마지막 검증 결과와 사용량 이벤트가 유지됐는지 확인합니다.
3. main.jsonl 및 필요한 경우 additional-sessions.zip만 로그 업로드에 사용합니다. 원본, .env.local, 인증 파일은 업로드하지 않습니다.
4. 제출 설명에 "API 키 등 비밀값만 마스킹했으며 실행 기록과 사용량은 유지"라고 적습니다.

artifacts/submission/은 Git에서 제외됩니다. 비밀값을 제거했더라도 세션 로그를 공개 저장소에 올리지 않습니다.
