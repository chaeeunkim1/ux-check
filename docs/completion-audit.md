## 제약과 실제 한계

공개 예제는 합성 데이터이며 실제 GS 사이트는 공개 화면만 읽었다. 회사 내부망·인증·사이트 수정·새 결제는 수행하지 않았다. 요청의 공개 IP/DNS 고정·읽기 전용·인증서 검증·요청 수·용량·시간 제한이 코드와 테스트에 있다. 사용량 제한은 인스턴스 메모리 기반으로 전역 과금 한도를 보장하지 않는다. 키는 서버 환경변수로 사용하고 공개 추적 파일의 정확한 비밀값 잔존 검사에서 일치 항목이 없었다.

AI 관찰 정확도와 업무 시간 절감률을 보장하거나 측정한 것처럼 주장하지 않는다. 정상 햄버거 메뉴·차단 iframe 공백 오탐은 실제 화면에 기반한 seeded 회귀로 제외되는 것을 확인했다. 이는 전체 정확도 검증이 아니다. 클릭·로그인·키보드에 대한 대상 사이트의 실제 동작과 전체 사이트 순회는 범위 밖이며 보고서에 명시한다.

## 충족하지 못한 실행 조건

오후 시작부터 다음 날 10시까지 세션이 멈추지 않아야 한다는 조건은 충족하지 못했다. Windows 대기 모드 구간과 이후 미확정 공백이 있었으며 execution-log.md와 원본 세션에 기록했다. 과거 중단을 지금 복구하거나 연속 실행이었다고 바꿀 수 없다. 10시 인계는 수행했으며 이후에는 남은 증거 확인과 인계 기록 보완을 했다.

따라서 제품·제출 자료의 준비 상태와 무중단 실행 조건의 미달을 구분한다. 미달 사실을 숨겨 원래 목표의 모든 조건을 충족했다고 표시하지 않는다. 대회 최종 제출 버튼은 사용자가 누르도록 남겼으며 에이전트의 작업 범위에서 제외된 행동이다.
