# 문제와 아이디어 · 제출 초안

GS건설 IT운영팀은 업무 시스템을 개선하거나 신규 화면을 검수할 때, 화면의 불편함을 찾아 업무 영향과 수정 요청으로 정리해야 합니다. 현장 담당자에게는 익숙하지 않은 상태 표시, 무엇을 입력해야 하는지 모르는 항목, 다음 행동이 불분명한 버튼처럼 작은 UI·UX 문제가 반복 문의와 잘못된 처리로 이어질 수 있습니다. 담당자마다 검수 경험과 설명 방식이 달라 발견한 문제를 개발자에게 전달하는 데도 시간이 듭니다. 현재 이 불편의 규모나 시간 절감 효과를 정량 측정한 것은 아닙니다.

만들고 싶은 것은 업무 맥락을 이해하는 AI 화면 검수 도구 ‘UX Check’입니다. 담당자가 검사할 사이트 URL과 “누가 어떤 작업을 완료해야 하는가”를 입력하면, 도구가 실제 페이지를 데스크톱·모바일 크기로 열고 AI가 화면과 문서 구조에서 관찰한 근거와 위치, 예상되는 업무 영향, 우선순위, 구체적인 개선안과 확인 기준을 정리합니다. 담당자는 AI 제안을 채택·보류·제외하고 보고서로 전달할 수 있습니다. 개선 전후 화면을 비교해 어떤 문제가 해소됐고 무엇을 더 확인해야 하는지도 살펴봅니다.

핵심은 화면에 점수를 매기는 것보다, 발견한 불편을 검토 가능한 근거와 실행할 수정안으로 바꾸는 것입니다. 공개 페이지와 합성 업무 예제로 검증하며, 사내망 접속이나 자동 로그인은 이번 공개 데모에서 제외합니다. 지정한 페이지에서 실제 확인한 범위를 명시하고, 스크린샷만으로 실제 동작이나 접근성 준수를 확정하지 않습니다. AI가 과잉 지적할 수 있다는 한계도 드러내고 담당자의 최종 판단을 남기도록 합니다.
