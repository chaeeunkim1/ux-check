# 제출 영상과 발표자료

- 공개 영상 페이지: https://ux-check-zeta.vercel.app/demo
- MP4: https://ux-check-zeta.vercel.app/demo.mp4
- 발표자료: https://ux-check-zeta.vercel.app/ux-check-presentation-final.pptx

영상은 1920×1080, 60.0초, 한국어 자막, 음성 없는 MP4이다. 실제 공개 배포에서 GS 채용 URL을 검사한 화면을 캡처해 편집했으며 분석 대기 구간 생략을 페이지와 자막에 명시했다. URL 입력 → 업무 목적 → 실제 결과 → 모바일 확대 → 담당자 판단 → 보고서 전달 흐름을 담았다. 전체 처리 시간이 60초라는 뜻은 아니다.

2026-09-22 09시대 공개 브라우저에서 재생 시작과 30초 장면을 확인했고, 끝까지 재생 후 duration=60, currentTime=60, ended=true, error=null을 확인했다. 이후 사용자가 새 시크릿 창에서 데모 실행·영상 재생·저장소 열람이 모두 정상이라고 확인했다.

발표자료는 편집 가능한 PowerPoint 7장과 약 5분 발표 메모를 포함한다. 구조·레이아웃·재입력 검사를 통과했고 7장 렌더를 각각 눈으로 확인했다. PowerPoint 앱에서 직접 열어 확인한 것은 아니다. 권장 1분·최대 3분 시연 영상과 결선 발표 5분·질의응답 3분을 구분한다.

10시대 마무리에서 테스트 31개와 GS건설 수집 실패 수정 사례를 반영한 최종 PPTX를 생성했다. 수정한 5번 슬라이드 렌더를 확인했으며 나머지 6장은 기존 검증 렌더와 바이트가 동일했다. 최종 파일 해시는 private validation.json과 일치한다.
