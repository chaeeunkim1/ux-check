# 제출 영상 규격

사용자가 전달한 대회 안내 기준입니다. 제품 구현 전에 확정한 제작 요구사항이며, 아직 영상을 제작하거나 검증한 것은 아닙니다.

- 권장 길이: 1분(60초)
- 최대 길이: 3분(180초)
- 기본 제작 목표: 55~60초 분량의 제출용 데모 영상 1개
- 결선 현장 발표 5분 및 질의응답 3분과 별도로 관리합니다.
- 영상 링크는 로그인이나 접근 권한 요청 없이 열리고, 브라우저에서 재생되어야 합니다.

## 60초 구성안

| 구간 | 내용 |
| --- | --- |
| 0~8초 | 업무 화면 검수에서 해결하려는 문제 |
| 8~15초 | 예제 화면 또는 캡처와 업무 목적 입력 |
| 15~40초 | 실제 AI 분석 결과에서 문제 위치·근거·개선안 확인 |
| 40~52초 | 개선 전후 비교와 검수 보고서 다운로드 |
| 52~60초 | 실제 동작 범위와 업무 활용 가치 |

실제 구현과 검증 결과에 맞춰 구성안을 조정합니다. 성능·효과 수치는 실측한 값만 사용합니다. 대기 구간을 생략하거나 배속하면 편집 사실을 표시해 실제 처리 속도로 오인하지 않도록 합니다.

## 최종 /goal에 포함할 문구

제출용 데모 영상은 권장 1분, 최대 3분 조건에 맞춰 55~60초를 목표로 제작한다. 실제 앱의 핵심 사용자 흐름을 녹화하고 한국어 자막으로 문제, 사용 방법, 분석 근거와 업무 활용 가치를 전달한다. 결선 현장 발표 5분 및 질의응답 3분과 영상 길이를 구분한다. 최종 인코딩 파일의 실제 재생 시간을 확인해 180초를 초과하지 않음을 검증하고, 공개 링크에서 로그인 없이 처음부터 끝까지 재생되는지 확인한다.

## 제작 후 확인

- [ ] 최종 파일의 실제 길이를 측정하고 기록
- [ ] 55~60초 목표, 최대 180초 준수
- [ ] 실제 작동하는 기능과 관찰한 결과만 포함
- [ ] 화면의 주요 문구와 한국어 자막을 읽을 수 있음
- [ ] 공개 영상 페이지에서 시작·중간·끝 재생 확인
- [ ] 제출 직전 시크릿 창에서 로그인 없는 전체 재생 확인

## 생성한 제출 자료
- 영상: public/demo.mp4, 1920×1080, 실제 길이 60.0초, 한국어 자막, 음성 없음.
- 공개 재생 페이지: /demo. 실제 공개 배포에서 GS 채용 페이지를 검사한 화면을 캡처해 편집했다. 분석 대기 구간 생략을 페이지와 자막에 명시했다.
- 발표자료: public/ux-check-presentation.pptx, 7장, 약 5분 발표용 메모 포함. 구조·레이아웃·재입력 검사를 통과했고 각 슬라이드 렌더를 직접 확인했다. PowerPoint 앱에서 직접 열어 확인한 것은 아니다.
- 공개 재생과 링크의 최종 확인은 배포 후 기록한다.
