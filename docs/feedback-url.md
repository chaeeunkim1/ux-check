## 실제 외부 사이트 피드백

GS 소개 페이지의 공개 브라우저 분석은 64.6초에 완료되었다. 도구 캡처와 일반 브라우저의 실제 화면을 직접 대조했다. H2 글자색은 실제 `rgb(0, 0, 0)`인데 초안에서 흰색이라고 설명했고 재검토에서도 그 항목을 남긴 오류가 있었다. 따라서 색상·문구 등 관찰 사실이 틀린 항목을 제목만 바꿔 남기지 않도록 재검토 기준을 강화했다. 장식 사진의 크롭·중첩과 반응형 브랜드 문구 생략을 업무 장애로 과장하지 않도록 했다.

실제 문서 높이는 약 5,889px였고 첫 화면 아래에도 주요 사업 설명과 링크가 있었다. 첫 화면만 보는 범위를 보완해 각 화면 크기에서 최대 3개 구간을 캡처하도록 구현했다. 최대 문서 높이 12,000px 안에서 상단·중간·마지막 확인 구간을 고르며, 구간 사이가 생략될 수 있음을 사용자와 보고서에 명시한다. 사이트 전체를 크롤링했다고 표시하지 않는다.

## 오탐 억제의 음성/양성 대조
- Example Domain: 정상 여백과 본문 안내를 결함으로 지적한 실패를 재현했다. 모델만 Opus로 바꾸어도 해결되지 않았다.
- 생성·재검토에 '관찰 사실의 정확성 + 구체적인 사용자 목적 방해'의 두 조건을 추가했다. 같은 캡처/초안에서 Sonnet과 Opus 모두 불필요한 4개 지적을 제외했다. 기본 모델은 Sonnet을 유지한다.
- 입력 폼 전후 비교 실제 회귀: 레이블/필수 정보가 보완된 점을 resolved로 유지했다.
- 승인 요청 화면 회귀: PC 대기 모드 중 연결이 끊겨 실패했다. 환경 복구 후 재실행한다.
- 다음 확인: 강화한 기준이 명확한 실제 결함까지 과하게 제거하지 않는지 합성 웹 페이지와 외부 페이지로 검증한다. 0개 결과도 정상 흐름으로 보여야 한다.


## 후속 확인 기록
승인 요청 화면 재실행은 52.498초에 성공해 실제 문제 3개를 유지했다. 제안했던 별도 합성 HTML 페이지는 9시 안정화 전환으로 구현하지 않았고 기존 합성 이미지 예제로 검증했다. URL 포함 보고서 3개 형식의 공개 다운로드는 확인했다. 최초 계획의 미확인 항목과 실제 완료 내역은 실행 로그 및 submission-handoff.md를 기준으로 구분한다.
