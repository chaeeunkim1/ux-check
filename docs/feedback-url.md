## 다음 반복 단위

1. 현재 공개 배포에서 한글 캡처와 실제 AI 결과가 일치하는지 확인.
2. 공개 GS건설 홈페이지 https://www.gsenc.com/ 등 실제 사이트로 접속·렌더링·모바일 관찰 확인. 접속 제한은 실패로 정직하게 기록.
3. 단순 페이지·내용이 많은 페이지·JavaScript 중심 페이지를 구분해 관찰 품질 비교.
4. AI가 없는 문제를 지적하거나 보이지 않는 동작을 확정하는지 원문 화면과 대조하고 프롬프트/검증 수정.
5. 사용자 흐름에서 잘못된 주소·시간 초과·취소·재시도·보고서 저장을 확인.
6. URL 중심 영상·발표자료·문제와 아이디어 문안을 맞추고 제출 근거 보존.

반복은 새로운 관찰이나 실패를 해결하는 데 사용한다. 동일 성공 요청을 사용량 증가만을 목적으로 반복하지 않는다. 오전 9시부터 배포 안정화, 10시 인계 준비에 집중한다.
