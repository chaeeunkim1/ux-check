## 실제 외부 사이트 피드백

GS 소개 페이지의 공개 브라우저 분석은 64.6초에 완료되었다. 도구 캡처와 일반 브라우저의 실제 화면을 직접 대조했다. H2 글자색은 실제 `rgb(0, 0, 0)`인데 초안에서 흰색이라고 설명했고 재검토에서도 그 항목을 남긴 오류가 있었다. 따라서 색상·문구 등 관찰 사실이 틀린 항목을 제목만 바꿔 남기지 않도록 재검토 기준을 강화했다. 장식 사진의 크롭·중첩과 반응형 브랜드 문구 생략을 업무 장애로 과장하지 않도록 했다.

실제 문서 높이는 약 5,889px였고 첫 화면 아래에도 주요 사업 설명과 링크가 있었다. 첫 화면만 보는 범위를 보완해 각 화면 크기에서 최대 3개 구간을 캡처하도록 구현했다. 최대 문서 높이 12,000px 안에서 상단·중간·마지막 확인 구간을 고르며, 구간 사이가 생략될 수 있음을 사용자와 보고서에 명시한다. 사이트 전체를 크롤링했다고 표시하지 않는다.
