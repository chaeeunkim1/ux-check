## 결과물 설명 문안

UX Check는 공개 사이트 URL과 사용 목적을 입력하면 실제 페이지의 데스크톱·모바일 화면을 확인하고 UI·UX 수정 제안을 정리하는 도구입니다. 한 페이지에서 최대 6개 스크롤 구간을 수집하고, Claude가 초안을 만든 뒤 근거를 재검토합니다. 사용자는 문제 위치·관찰 근거·예상 영향·개선안·확인 기준을 살펴보고 채택·보류·제외 판단을 남겨 HTML·Markdown·JSON 보고서를 저장할 수 있습니다. 화면 업로드와 합성 업무 예제, 개선 전후 이미지 비교도 제공합니다. 실제 로그인·클릭·입력·전체 사이트 탐색은 수행하지 않으며 AI 제안은 담당자의 확인이 필요합니다.

## 검증한 것과 남은 것

- 자동 테스트 30개, 프로덕션 빌드 및 GitHub CI가 통과했다.
- GS 소개·채용 페이지에서 공개 URL 수집 및 실제 Claude 분석을 확인했다. GS건설 홈페이지에서도 수집·실제 AI 분석이 143.514초에 성공했다. 이후 한국어 브라우저 설정과 AI 좌표 오류 복구를 보완하고 공개 UI에서 국문 4개 화면 수집·실제 분석 70.7초·결과 3개 표시를 확인했다. 과잉 지적은 담당자 판단으로 제외했으며 AI 정확도를 보증하지 않는다.
- 승인 목록·입력 폼·업무 대시보드 합성 예제와 전후 비교의 실제 API 결과를 보존했다.
- 공개 영상의 시작·30초·끝, 총 60초 및 재생 오류 없음을 확인했다.
- 공개 GitHub가 로그아웃 상태에서 Public으로 열리고 코드·README가 보였다.
- 데모·영상 페이지·MP4·PPTX·GitHub를 쿠키/인증 없는 HTTP 요청으로 확인해 모두 200과 실제 내용을 받았다.
- 발표자료 7장의 렌더와 구조를 확인했다. PowerPoint 앱 직접 실행은 미실시다.
- 사용자가 새 시크릿 창에서 데모 실행·영상 재생·공개 저장소 열람을 모두 정상 확인했다고 회신했다. 대회 최종 제출은 사용자에게 남아 있다.

## 알려진 한계

AI의 근거 재검토 후에도 오탐이 남을 수 있다. 화면 경계 잘림, 장식 표현, 접근성 이름 추정 등을 보수적으로 다루도록 개선했으나 정확도나 시간 절감 효과를 정량 입증하지 않았다. 위치 마커는 근사치다. 짧은 관찰 구간 사이와 12,000px 이후는 누락될 수 있다. 접속 제한·큰 리소스·일시적 네트워크 오류가 있는 사이트는 수집에 실패할 수 있다. 일부 차단 리소스 때문에 실제 화면과 다를 수 있다. 메모리 기반 사용량 제한은 서버 전체의 확정 과금 한도가 아니다.

Windows 대기 모드 및 이후 미확정 중단으로 밤새 연속 실행하지 못했다. 중단 구간을 개발 시간으로 설명하지 않으며 실패·공백·수정 이유를 세션과 실행 기록에 보존한다.

## 제출 직전 사용자 조작

1. 시크릿 창 세 링크 확인은 사용자가 완료했다. 제출 직전 링크를 바꾸면 다시 확인한다.
2. PPTX를 열어 발표자 이름 등 필요한 정보와 발표 메모를 확인한다.
3. 대시보드에 문제/아이디어, 실제 /goal 원문, 비밀값을 제거한 주 JSONL·추가 ZIP, 세 공개 링크, 발표자료, 결과 설명을 입력한다.
4. 링크와 파일을 다시 확인한 뒤 9월 22일 12시 전에 최종 제출한다. 에이전트는 최종 제출 버튼을 누르지 않았다.

## 3분 질의응답 준비

- 왜 기존 AI 채팅과 다른가? URL의 실제 화면을 수집하고 구간별 근거, 재검토, 담당자 판단과 전달 보고서를 한 흐름으로 연결했다.
- 잘못된 지적은 어떻게 처리하는가? 두 번째 검토에서 근거 없는 항목을 제외하고 불확실성을 표시한다. 최종 판단은 담당자가 하며 정확도를 보증하지 않는다.
- 사내 시스템에도 바로 쓸 수 있는가? 현재 공개 데모는 내부망과 자동 로그인을 차단한다. 사내 적용에는 별도 내부 실행 환경, 데이터 취급 검토와 실무 평가가 필요하다.
- 에이전트를 어떻게 위임했는가? 실제 /goal에 결과·완료 기준·제약·판단 범위·실패 수정과 종료 조건을 지정했다. URL 중심으로 정정한 이유도 기록했다.
- 효과는 얼마나 검증했는가? 실제 사이트 및 합성 업무 예제의 기능 실행을 검증했다. 검수 시간 절감률이나 정확도 수치는 아직 측정하지 않았다.
