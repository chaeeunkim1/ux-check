- 스크린샷 렌더링에서 작은 보조 문구가 흐려 보이는 것을 확인해 글자 크기와 대비를 보강했다.
- 공개 호출 제한은 서버 인스턴스별 메모리 기반이다. 전역 영구 과금 한도로 보장하지 않으며 현재는 인스턴스당 시간당 40회, 클라이언트당 10회, 동시 3회이다.
